В проекте были сравнены три подхода к классификации 77 банковских интентов. TF-IDF с Logistic Regression показал сильный baseline с macro F1 0.8613 при минимальном времени обучения. Transformer Encoder, обученный с нуля, получил macro F1 0.8241 и уступил baseline, поскольку небольшого размеченного датасета оказалось недостаточно для самостоятельного обучения языковых представлений. Fine-tuning предобученного DistilBERT повысил macro F1 до 0.8818 и сократил число ошибок на validation с 270 до 217. Результаты показывают, что преимущество Transformer проявилось благодаря предобучению, но улучшение качества сопровождается существенным ростом вычислительной стоимости.

DistilBERT — лучшая модель по качеству.
TF-IDF — лучшая модель по соотношению качество/скорость.
Transformer с нуля — учебный эксперимент, который показывает понимание архитектуры, но не является кандидатом для внедрения.
